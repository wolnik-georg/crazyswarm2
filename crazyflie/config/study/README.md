# Study yaml variants (2026-10-11)

`crazyflies.yaml` on main is the **S0** configuration (controller 6, ctrl_mode 0, ki_z 16, rnn.en 0, res_sign −1, dormant Omar block with Kpos_Iz 1.5).
`S1.patch` (controller 9), `S2.patch` (rnn.en 1) and `ours.patch` (ctrl_mode 3, ki_z 0, res_sign 1) turn it into the other strategies; each was verified to apply and
to pass the frozen-block check (`study_strategies.json`) with `lab_preflight.py --study` (generated by `experiments/analysis/study_yaml_variants.py` in the thesis repo).

`make_tags.sh` creates the tags `study-S0/S1/S2/ours` (dry run by default) — run it after the NS2 and Pure-INDI decisions, then `git push origin --tags`.
Use in the lab: `git fetch --tags && git checkout study-S1 -- crazyflie/config/crazyflies.yaml`, relaunch, `lab_preflight.py --study S1`, `run_formation --study --strategy S1 …`.
